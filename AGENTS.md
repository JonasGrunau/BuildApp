# BuildApp

## Purpose
Psytrance buildup effect (VST3 / AU, JUCE 8). One chain: pitch (0..+12 st), low cut (left = off) and high cut (right = off) in FabFilter Volcano 3 style filters with a type menu and a resonance knob each (auto resonance on by default), white noise volume, pitch and low cut (200 Hz default), a one-knob buildup reverb, stereo narrowing (100 % default), level, dry/wet. Every knob at rest passes the signal bit for bit. Offline renders run the cuts oversampled. The editor shows the live input/output spectrum with the cuts' exact response and the noise band. Ten presets (`Presets.h`) lock the controls they use to a path along one BUILD knob (level and dry/wet always stay free); BUILD 0 is at rest.

## For AI Agents

### Working In This Directory
- Core loop (seconds): `cmake -B build-core -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILDAPP_BUILD_PLUGIN=OFF && cmake --build build-core && ./build-core/buildapp_tests`
- Full plugin: `cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build` (installs into `~/Library/Audio/Plug-Ins`). A local JUCE: `-DFETCHCONTENT_SOURCE_DIR_JUCE=...`.
- Never include JUCE from `src/core`. New `.cpp` files go into `CMakeLists.txt` by hand.
- Audio thread: no allocation or locks in `processBlock` / `Buildup::process`. Buffers are sized in `prepare`.
- A stage's smoothers only advance while it runs: a silent stage snaps its targets (`setTargets`), so it wakes up where the knob is. Keep that when adding stages.
- At-rest exactness is tested (`Chain: every knob at its default passes the loop bit for bit`): a stage at rest must return early, not multiply by 1.
- Presets: every amount lane starts at rest (BUILD 0 is bit-exact, tested at 3 rates); a cut lane comes with its type; never drive level or mix. The preset index is the save format: append new presets at the end of `kPresets`. After changing one, run `buildapp_render` and keep it inside the `[level]` window (-6.5..+2.5 LU re the dry loop when held at each quarter). Presets never write parameters: the processor's `settings()` applies them, so Off brings the user's knobs back.
- JUCE 8 API: text widths via `theme::textWidth`; numbers via `fmt::` (`src/plugin/Format.h`), never `juce::String (x, 0)`.

### Testing Requirements
- After core changes: `./build-core/buildapp_tests` must pass (presets at rest, lane shape, loudness window, distinct paths, the drop back to bit-exact; halfband rejection, filter response vs computed for every type, slopes, auto resonance ranges, click-free switching, HQ aliasing, pitch intervals, tone residual, chord artifacts and kick timing, noise level and low cut, reverb RT60 and drop, bit-exact rest, all rates).
- New cut types: add to `Characters.h`, then check the bump along the sweep stays under +14 dB (the auto-resonance test) and that `Cut filters: every type sweeps the loop bounded` passes.
- After UI changes: build `buildapp_snapshot`, render `<dir>` (and `<dir> --scale=1`) and read the PNGs; `steps` shows the menus' `<` `>` keys hovered, held and dimmed.
- Before a release: `auval -v aufx BdAp Jgru` and pluginval at strictness 5 on both formats.

### Common Patterns
- Namespaces: `ba` (core), `ba::dsp` (primitives), `ba::map` (knob meanings), `theme` (UI tokens and helpers), `fmt` (number text). Plugin/UI classes are global.
- JUCE-style formatting: space before call parens `foo (x)`, 4-space indent, braces on their own line.
- Look ("night sheet", PhaseFucker's sibling): sheet `#131211`, bone ink `#ECE7DB`, one acid accent `#C8F03C` only for what builds tension (cut curve, build-knob rings); no gradients, shadows or glow; corner radius 2 px; IBM Plex Sans Condensed labels, IBM Plex Mono numbers.
